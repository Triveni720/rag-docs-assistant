# MuleSoft Anypoint Platform

MuleSoft Anypoint Platform is an integration platform used to build, deploy and manage APIs and integrations that connect applications, data and devices.

## API-led connectivity

API-led connectivity organises APIs into three layers. System APIs unlock data from core systems such as Salesforce or a database. Process APIs combine and orchestrate data from several system APIs. Experience APIs shape the data for a specific consumer such as a mobile app or web portal.

## RAML

RAML (RESTful API Modeling Language) is a YAML-based language used to design an API specification before building it. In Anypoint Design Center a developer writes the RAML, mocks the API and shares it for feedback.

## DataWeave

DataWeave is MuleSoft's transformation language. It converts data between formats such as JSON, XML and CSV, and maps fields from one structure to another.

## Deployment

Mule applications can be deployed to CloudHub, MuleSoft's managed cloud, through Runtime Manager. API Manager applies policies such as Client ID Enforcement, Basic Authentication and rate limiting to secure APIs.
